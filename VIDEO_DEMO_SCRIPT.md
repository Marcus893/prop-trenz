## Tips for Recording:

1. **Use a clean browser** - Clear cache, use incognito if needed
2. **Slow down interactions** - Give viewers time to see what's happening
3. **Highlight key features** - Use cursor movements or zoom to draw attention
4. **Show data variety** - Use different cities/municipalities to show breadth
5. **Smooth transitions** - Avoid jarring cuts, use fade transitions
6. **Good lighting** - If doing screen recording, ensure good contrast
7. **Clear audio** - Use a good microphone, minimize background noise


---

## Notes:
- Adjust timing based on your speaking pace
- Add pauses for emphasis on key features
- Consider adding background music (subtle, instrumental)
- Include captions/subtitles for accessibility
- End with a clear call-to-action (sign up, visit website, etc.)

## Consejos para la Grabación:

1. **Usa un navegador limpio** - Limpia la caché, usa modo incógnito si es necesario
2. **Ralentiza las interacciones** - Dale tiempo a los espectadores para ver lo que está pasando
3. **Destaca características clave** - Usa movimientos del cursor o zoom para llamar la atención
4. **Muestra variedad de datos** - Usa diferentes ciudades/municipios para mostrar amplitud
5. **Transiciones suaves** - Evita cortes bruscos, usa transiciones de desvanecimiento
6. **Buena iluminación** - Si estás grabando la pantalla, asegura buen contraste
7. **Audio claro** - Usa un buen micrófono, minimiza el ruido de fondo
